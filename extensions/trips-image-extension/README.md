# Trips Image Extension (Chrome)

DuckDuckGo image search in **Chrome's native side panel** when you select an attraction on a Trips map or form.

No build step — load unpacked directly from `extensions/trips-image-extension`.

## Setup

1. `chrome://extensions` → **Developer mode** → **Load unpacked**
2. Select `extensions/trips-image-extension`

## Usage

1. Open a Trips map or attraction verify form and select an attraction (map marker or Search images button)
2. Chrome's side panel opens on the right with a 2-column image grid
3. Toggle via the extension toolbar icon

## After editing extension files

Click **Reload** on `chrome://extensions` — no build required.
