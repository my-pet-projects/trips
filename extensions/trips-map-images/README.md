# Trips Attraction Images (Chrome Extension)

DuckDuckGo image search in **Chrome's native side panel** when you click a marker on any Trips map.

No build step — load unpacked directly from `extensions/trips-map-images`.

## Setup

1. `chrome://extensions` → **Developer mode** → **Load unpacked**
2. Select `extensions/trips-map-images`

## Usage

1. Open any Trips map page and click a marker
2. Chrome's side panel opens on the right with a 2-column image grid
3. Toggle via the extension toolbar icon

## After editing extension files

Click **Reload** on `chrome://extensions` — no build required.
